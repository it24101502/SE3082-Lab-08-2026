Exercise 07 was implemented by replacing the standard blocking send operation (MPI_Send) used in Exercise 06 with the buffered send operation (MPI_Bsend). A user-defined buffer was attached using MPI_Buffer_attach() before sending the message. The receiver used MPI_ANY_SOURCE, allowing it to accept messages from any sending process. The program executed successfully and produced the output "Process 0 sent 42" and "Process 1 received 42". Compared to Exercise 06, the communication result was the same, but MPI_Bsend() stores the outgoing message in a buffer and allows the sender to continue execution without waiting for the receiver.
